# Sound Files

วางไฟล์เสียงในโฟลเดอร์นี้ รองรับ .mp3 / .wav / .ogg

## Voice Prompts
| ไฟล์ | หน้าจอ | เนื้อหาแนะนำ |
|---|---|---|
| `voice_welcome.mp3` | หน้าแรก (KioskPanel) | "ยินดีต้อนรับ กรุณากดเริ่มต้น" |
| `voice_breathing.mp3` | ทดสอบแอลกอฮอล์ (BlowPanel) | "กรุณาเป่าลมหายใจเข้าในท่อ" |
| `voice_result_pass.mp3` | ผลผ่าน (ResultPanel) | "ผลการทดสอบผ่าน" |
| `voice_result_fail.mp3` | ผลไม่ผ่าน (ResultPanel) | "ผลการทดสอบไม่ผ่าน" |
